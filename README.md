# Lead Sheets

An offline lead sheet and tab viewer that installs to your phone's home screen. Live mode shows only chords and lyrics, with auto-scroll and PREV/NEXT. Edit mode has an Infer Format button that tidies pasted text. Tools mode holds the tuner, metronome and Keys & chords.

- **Songs stay on the device.** They are stored in the browser's IndexedDB. This repository contains no songs.
- **Search:** the search box matches title, artist, album, genre and the `Meta:` line, which takes comma-separated values (`Meta: opener, slow, drop D`). Use `artist:`, `genre:` or `meta:` to narrow a search to one field.
- **Setlists:** pick By Setlist in the list. In Edit mode, tap + New setlist at the bottom, or the pen on a setlist, to name it, add songs, drag them into order and set each song's capo and tempo for that set (past fret 0 or 7 the shapes change instead). In Live mode, tapping a song plays the set in order with those settings. A song can be on any number of setlists. Setlists are included in Export and Import.
- **Tags:** header lines such as `Key:`, `Capo:`, `Tuning:` and `Notes:`. A `Notes:` line can also sit anywhere in the song and shows there as a note. A `*` after a chord (`A*`) is kept as a marker. A `Key change: A` line in the song marks a modulation; numbers restart from the new key. Settings → Live settings → Live tags picks the tags shown above the sheet, and the ⓘ button in Live lists them all.
- **Key and capo:** `Key:` is the sounding key and the chords are the shapes you play, so `Key: D` with `Capo: 2` and C shapes shows C as 1.
- **Live controls:** Capo (−/+) moves the capo and keeps the shapes, so the key changes but the chords you play don't. Transpose (−/+, shown as a semitone shift) changes the key and the chord shapes. Tap either value to reset. Chord numbers (needs a `Key:`; Nashville or Roman, picked in Settings → Live settings → Numbers) replace chords with numbers and follow the shapes. All of these change only what is shown, never the saved song. Settings (⋮ in the list) → Live settings → Top bar shows or hides these, the ⓘ song details button, the tuner and the metronome; Numbers (Nashville or Roman) appears when the Numbers control is on; Bottom bar shows or hides the auto-scroll and Prev / Next buttons (the bar disappears when both are off). Text size sets the sheet size. The ⋮ menu in Live has the same Live settings plus Edit song and Share song; Preview in the editor returns to the song in Live.
- **Tuner and metronome:** the Live header has a guitar button (chromatic tuner, uses the mic) and a metronome button. The metronome starts at the song's `Tempo:` or the setlist's tempo, and Tap sets it; tapping the Tempo or Beats number lets you type a value. Beats sets the bar length (1–16), and tapping a beat's square cycles it through primary click (filled), secondary click (inset square) and silent (empty); the pattern is remembered across songs. Closing its dialog keeps it clicking. Settings → Live settings → Top bar shows or hides both. Tools mode in the list shows the tuner, metronome and Keys & chords as sections that expand in place, and several can be open at once. The tuner only listens to the mic while its section is open. Tools remembers which of the metronome and Keys & chords were open; the tuner always starts closed. The metronome keeps clicking when its section is collapsed (its icon pulses on each beat) and stops when you leave Tools. When a section is open its title gives way to its main controls: Tap and Start for the metronome, the tuner's status line, and the view switcher for Keys & chords. Keys & chords opens on the circle of fifths: tap a wedge to hear its note (or chord, with Play → Chord) and select its key, which highlights the key's chords on the circle and lists them with Roman numerals; the inner ring holds the relative minors (in lowercase, as am, em…). The F♯/G♭ and d♯m/e♭m wedges show both names stacked, with the spelling the selected key uses on top. The lock button keeps the selected key while you tap other wedges to hear them. Wedges and chords sound while held and fade on release. Tapping a chord under the circle plays it, and the chord and its wedge press down together. The key's diminished chord appears as a single wedge in the innermost ring. Notes sound in the octave that starts at the selected key's tonic, so the chords from I to vii° rise in pitch. The view switcher, which takes the place of the card's title when it is open (the selected view shows its name, the others just their icons), shows the same key and chord as Fifths, Clock (the 12 notes around a clock, the key as a faint shape and the chord as a triangle named in the centre, with the voicing moving notes between octave rings), Intervals (one row per chord across 12 half steps, lined up on each chord's root), Notes (the same rows lined up on the key) or Keys (a three-octave keyboard). Every note, dot, cell and key plays while held, and tapping a chord selects it for all views. Chord mode is the default. In Note mode the buttons become scale degrees (1–7 with plain note letters), the circle drops the m and ° from its labels, and Clock, Intervals, Notes and Keys show the selected single note instead of a chord. Play → Scale swaps the buttons for scales (the seven modes from the tonic, plus major and minor pentatonic); tapping one plays it up an octave and every view shows it. In Chord mode, Voicing (R / 1 / 2) picks root position or an inversion for every chord played. Lock keeps the key on the Fifths view; on the other views it greys out and disables every note outside the selected chord (Chord), the key (Note) or the scale (Scale). The root of the chord, note or scale is drawn in lime on Clock, Intervals, Notes and Keys.
- **Page turner:** Bluetooth pedals and keyboards work in Live. Page Down, ↓ and → go forward; Page Up, ↑ and ← go back. Settings → Live settings → Page turner picks Page (scroll a screen, then turn to the next song at the end) or Song (always change song). Space plays or pauses auto-scroll.
- **Editor:** Preview saves and shows the song in Live with an Edit button. Settings → Editor → Fix Format On Preview runs Infer Format each time you tap Preview.
- **Sharing:** long-press a song in the list (or tap its ⋮ when Settings → Song list → Song Menus is on, or ⋮ → Share song in Live) and tap Share song to send a link to Messages or any other app; the song is compressed into the link itself. Opening the link adds the song, or finds an identical copy already in the library. Opening it shows the song in Live.
- **Backup:** in the list, tap ⋮ and then Share library to save or send all songs and setlists as one compressed `.json.gz` file. Import restores that file or an older `.json` backup, or adds a single `.md`/`.txt` song.
- **Install:** host the folder on GitHub Pages, open the URL on your phone, then Share → Add to Home Screen.
- **Run locally:** serve the folder with any static server and open the printed localhost URL. Do not open `index.html` as a `file://` URL, because the service worker and modules need http(s).
  - Python: `py -m http.server 8000` on Windows, `python3 -m http.server 8000` elsewhere → `http://localhost:8000/`
  - Node: `npx serve .` → `http://localhost:3000/`
  - Tests: open `/test/` on the same server.
- Icons: [Font Awesome Free](https://fontawesome.com) 6.7.2, CC BY 4.0, bundled in `js/core/icons.js` so the app works offline.
